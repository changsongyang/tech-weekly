首先看监控

监控面板，反馈从正常到异常的趋势图，时间点，找到关键可疑点。

CPU、负载和内存

CPU：Java FGC 太多，是否是 CPU 密集型计算，比如加密计算、AI 推理、矩阵计算

负载：Load 偏高，CPU 引起，锁：连接池、线程池、死锁

内存：内存泄露，JVM Heap Metrics 可以被采集，Micrometer、或者 OpenTelmetry 等、公有云服务提提供商、zabbix（内存）
